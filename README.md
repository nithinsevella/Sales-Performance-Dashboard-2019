# Project Title: Sales Performance Dashboard – 2019

## Overview
This project delivers an end-to-end sales performance analysis for the year 2019 using Microsoft Excel. It transforms raw sales data into an executive-level dashboard that highlights key performance metrics, geographic revenue distribution, risks, and actionable business insights to support decision-making.

---

##  Features
- **Executive KPI Dashboard:** Displays Total Revenue, Total Orders, Average Order Value (AOV), Month-over-Month (MoM) Growth %, and Revenue Concentration %.
- **Trend Analysis:** Monthly sales trend visualization to identify seasonality and performance patterns.
- **City-Level Analysis:** Comparison of top-performing and underperforming cities.
- **Revenue Contribution Analysis:** Highlights dependency on top cities using contribution percentages.
- **Interactive Dashboard:** Month and City slicers for focused analysis.

---

## Tech Stack
- **Tools:** Microsoft Excel (Pivot Tables, Pivot Charts, KPI Tiles, Slicers)
- **Techniques:** Data Cleaning, Aggregation, Trend Analysis, Contribution & Concentration Analysis
- **Version Control:** Git & GitHub
